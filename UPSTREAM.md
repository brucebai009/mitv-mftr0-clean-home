# Upstream and independence

TVHome is an independent derivative of the public CleanYourTV project at `https://github.com/Gathin23/cleanyourtv`.

The upstream project is retained under its original license and attribution. This repository adds a device-specific profile, safe wallpaper import, and guarded deployment tooling. It does not represent Xiaomi, Gathin23, or any TV manufacturer, and it does not redistribute proprietary firmware or system applications.

# v13.18 release status

This branch contains the incremental TVHome artwork/card update from the MFTR0 v13.18 device candidate. The source uses the normal public Maven dependency for AndroidX core; local offline build helpers and the release keystore are not part of the branch.

The TVHome candidate was installed and its package/signature/HOME return were verified on the target MFTR0 device. The companion GlassBox APK was not published as a tested binary because its local Gradle/plugin toolchain was unavailable. The supplied Emby archive did not contain a complete installable APK, so no Emby binary is published or renamed here.

See the local v13.18 return package for raw device evidence and the exact blocked-input analysis.

# TVHome v13.18.1 — HDMI-CEC routing and pearl artwork

This patch extends the v13.18 source without changing the installed launcher identity or user-data schema. Version code: 27. Version name: `1.0.0-v13.18.1-hdmi-cec`.

HDMI-CEC children now reuse their physical parent's existing, exact device-profile route. Direct physical mappings still take priority; unknown parents keep the generic fallback. A PS5 CEC child on the tested MFTR0 firmware was selected through TVHome's menu and produced the actual HDMI3 picture with the native `3840x2160@60Hz` overlay. HDMI1 and HDMI2 opened the correct native port pages; live sources were not attached to those ports.

Apple Music TV (`com.applemusic.lavande`) has a bundled, full-card pearl/chrome banner. Explicit theme artwork takes priority. Dock and library use the same binding path, preserving card size, clipping and focus animation. Focused and unfocused screenshots were inspected on the television.

The signed release APK is the exact package cover-installed and checked on the target TV. It uses the existing `com.ts.launcher` compatibility identity and original release certificate. Build that identity explicitly with `-PlauncherApplicationId=com.ts.launcher`. Default source builds retain the original application ID. The public Gradle file uses normal Maven dependencies; local SDK paths, offline jars, signing material and private device logs are not published.

The target TV's selected video wallpaper, playlist settings and Dock order were compared before/after and retained. Native HOME resolver and actual foreground were verified after returning from applications and HDMI. This patch did not repeat coldboot, reboot, standby or a physical-remote no-flash acceptance run; previous-version results are not claimed as new evidence.

Release APK SHA256: `b94c29c691f3ab306bed491d6c5d6b38a25a2820d8c132d2123f4c2448ab07ee`.

Release certificate SHA256: `8edb7ec47cf01743c0059740451a0dc4570b5312fe4c0e06c83595948f95d595`.

For an existing installation with that identity and certificate, use `adb -s <TV_IP:PORT> install -r TVHome-v13.18.1-HDMI-Pearl.apk`; keep the current HOME setup. The legacy root installer is locked to an older package/SDK contract and is not the installer for this compatibility APK.

The bundled raster banner increases APK size. CI retains a 2 MiB package-size budget and labels automated unsigned handoffs without the obsolete v13.2 name. The downloadable signed APK is provided separately from unsigned CI artifacts.
